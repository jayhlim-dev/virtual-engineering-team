# Shared project memory

This folder is the team's source of truth for one project.

| File | Purpose |
| --- | --- |
| `TEAM_RULES.md` | How the team works |
| `PROJECT_CONTEXT.md` | Product, stack, conventions |
| `ARCHITECTURE.md` | Verified architecture only |
| `DECISIONS.md` | Why we chose something |
| `task-board.json` | Task status and owners |
| `agents/` | Specialist instructions |
| `tasks/` | Full task records |
| `handoffs/` | Specialist-to-specialist packets |
| `reports/` | Final delivery reports |

Do not store secrets here.
